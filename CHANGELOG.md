# Changelog

## 1.0.0 — 2026-10-31

First release.

- Variable font built from the four static Open Runde 1.0.1 weights.
- Weight axis (`wght` 400–700) with named instances Regular, Medium, Semibold and Bold.
- Roundness axis (`ROND` 0–100), from sharp corners to Open Runde's soft ones.
- TTF and WOFF2, licensed under the SIL Open Font License 1.1 with the original Inter and Open Runde notices.
- Specimen site with live weight and roundness controls, a type scale, long-form text and a filterable glyph table.
